# 示例会话 / Demo session

> 以下是一次典型对话，展示「问答模式」如何先详尽澄清、总结确认、再执行。
> A typical session showing how the preset clarifies first, confirms, then acts.

## 用户 / User

帮我写一个 Python 脚本，定时清理 C 盘的临时文件。

## 助手 / Assistant

我先确认一下我的初步理解：你想让我写一个在 Windows 上定期运行的 Python 脚本，自动清理 C 盘的临时文件。动手之前，我需要先问清楚几个关键问题。

**第 1 轮提问**（选择题摘要）：

1. 目标与背景：这是个人电脑日常维护，还是部署在多台机器/服务器上的运维任务？
   - 个人电脑 (Recommended)
   - 服务器/多机部署
2. 范围与边界：清理哪些位置？（可多选）
   - `%TEMP%` 用户临时目录 (Recommended)
   - `C:\Windows\Temp`
   - 浏览器缓存
   - 回收站
   - 其他（请说明）
3. 约束条件：删除策略如何把握？
   - 只删超过 N 天未修改的文件 (Recommended)
   - 立即全部删除
4. 风险与兜底：误删保护怎么做？
   - 先移到回收站，N 天后彻底删除 (Recommended)
   - 直接永久删除
5. 执行方式偏好：直接写脚本，还是先给你一份实现方案？
   - 直接写 (Recommended)
   - 先看方案
6. 沟通与详略偏好：代码注释与说明要多详细？
   - 关键步骤注释 + 使用说明 (Recommended)
   - 极简
7. 上下文与背景：脚本用什么方式定时运行？
   - Windows 任务计划程序 (Recommended)
   - 脚本自带循环
   - 其他

## 用户 / User

1 个人电脑；2 只清理 %TEMP% 和 C:\Windows\Temp；3 只删超过 7 天的；4 先移入回收站；5 直接写；6 关键注释即可；7 用任务计划程序。

## 助手 / Assistant

明白了，我总结一下我的理解，请确认：

- **目标与背景**：个人电脑日常维护，清理临时文件释放磁盘空间。
- **范围与边界**：只清理 `%TEMP%` 与 `C:\Windows\Temp`，不动浏览器缓存、回收站等其他位置。
- **约束条件**：只删除最后修改时间超过 7 天的文件；空目录一并清理。
- **风险与兜底**：被删文件先送入回收站，不直接永久删除。
- **执行方式偏好**：直接写代码。
- **验收标准**：脚本可在本地运行；手动执行一次即可完成清理并输出报告；可被任务计划程序调用。
- **沟通与详略偏好**：关键步骤注释 + 简要使用说明。

**仍不确定的项**：无。
**我将采用的默认假设**：Python 3.10+；回收站操作优先使用标准库可实现的方式，若需第三方库会写入依赖说明。

请回复「确认」或指出需要修改的地方。

## 用户 / User

确认。

## 助手 / Assistant

✅ 已确认，开始执行。这是一个小任务（单文件脚本），我直接编写。

（随后产出 `clean_temp.py` 与使用说明，并在结果中说明执行中的假设。）

## 打断示例 / Interrupt example

用户提问中途说：「跳过提问，直接开始」。

助手立即停止提问并输出：

> 好的，我将按以下初步理解执行，请确认：
>
> - 理解要点：写一个定时清理 C 盘临时文件的 Python 脚本。
> - 仍不确定的项：清理范围是否包含 `C:\Windows\Temp`。
> - 默认假设：仅清理 `%TEMP%`，其余位置不动。
>
> 请回复「确认」后我开始执行。
